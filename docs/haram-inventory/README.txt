Haram location inventory preparation

Use Django admin to enter records. The CSV is a blank collection template; automatic CSV import is not included.
Do not invent gates, service positions, translations, access restrictions or availability.
Languages are unique supplied language codes such as ar, en, ur, id, bn, tr, fr, ms. This field describes availability, not translated text.
Local x/y/z coordinates are relative to the Haram architecture origin in illustrative model units. They must be calibrated against the approved layout before publication. Do not derive them from the old crowd zone cylinders.
Floor convention: -1 basement, 0 ground, 1 first, 2 roof. Confirm official floor names before entry.

UNVERIFIED records remain disabled. APPROXIMATE records show a visible warning. VERIFIED means source reviewed; it never means the whole building geometry is surveyed.
Review both names, geographic coordinates, model position, floor, source and verification date with another team member before enabling. Admin does not implement a separate two-person approval system.
Notes are PUBLIC. Keep confidential comments and source credentials out of every field. source_url is not published.
