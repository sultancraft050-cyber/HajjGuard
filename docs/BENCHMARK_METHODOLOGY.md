# Benchmark Methodology

Only measurements generated from raw inputs are acceptable. The benchmark command now refuses to invent MAE, routing reduction, battery, offline, or false-alarm values; those fields are `NOT MEASURED` until the required scenario, device, browser, or labeled data exists. The committed JSON is an explicit not-generated marker.

Required evidence includes dataset/scenario hash, code commit, environment, configuration, warm-up, trial count, raw timings, aggregation, failures, and reproduction command.
