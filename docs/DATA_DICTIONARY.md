# Data Dictionary

Primary entities are User, PilgrimProfile, AuditLog, HajjCampaign, NusukCard, Zone, Corridor, LocationPing, DensityRecord, CameraSnapshot, SosIncident, FieldUnit, Alert, PilgrimGroup, and GroupMembership. Location pings are raw telemetry subject to retention. QR payloads contain an opaque card reference and routing metadata only.
